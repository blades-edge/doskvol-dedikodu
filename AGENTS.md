# Depo yönergeleri

Bu depoda Git ve GitHub için yazdığınız içeriği Türkçe hazırlayın. Bu kural commit mesajlarını, PR ve issue başlıklarıyla açıklamalarını, inceleme yorumlarını ve diğer GitHub yorumlarını kapsar. Conventional Commits kullanırken `feat:` ve `fix:` gibi teknik önekleri koruyun, önekten sonraki açıklamayı Türkçe yazın.

CSS'te breakpoint'ler ve sabit yerleşim genişlikleri için `rem` kullanın. Diğer ölçülerde de uygun olduğunda `rem`, `em` ve `ch` gibi tipografiye bağlı birimleri tercih edin.
